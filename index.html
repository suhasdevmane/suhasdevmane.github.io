Ask your building anything in plain English.

Connect a building's Brick model and its sensor databases, then ask questions in plain English. Answers come from the building's own data, name their sources, and say so when the data is not there. No SQL, no SPARQL, no schema knowledge needed.

Why OntoSage

Grounded answers, any stakeholder, any building.

One natural-language interface over a single building's own data, designed so that each figure in an answer traces back to a triple, a database row or a floor plan.

🎯

Grounded in the building's data

Figures are computed from the graph, a database or a floor plan, and the answer names its sources. If a place or reading is missing, OntoSage says so.

🧩

Routed to the right lane

Each question is classified and sent to a lane built for it: readings, trends and forecasts, ranking spaces, records, floor plans, documents or report intake.

💬

Lay terms to Brick classes

"Stuffy" resolves to CO₂ and "too warm" to temperature. Experts can still use Brick class names and a SPARQL browser.

🏢

Building-agnostic

Add a building from the admin console or by dropping files into input/: identity, Turtle, databases, documents, floor plans. No code change.

🔒

Administrator-controlled access

Every data and admin endpoint needs a permission: 6 roles, 22 permissions. Personas change how an answer is framed, never what a person may see.

⚙️

Local or API models

Run the language model on local Ollama (gpt-oss:20b), OpenAI, Ollama Cloud or an OpenAI-compatible gateway. Embeddings are chosen separately.

How it works

Connect data → get answers.

A reading is answerable when the sensor is a triple in the graph and its readings are rows in a registered database. Adding a building is configuration and data, not code.

Connect the building

Load the Brick Turtle and register its databases. Each sensor's ref:storedAt names the database that holds its readings.

Ask in plain English

The question is classified, a follow-up is rewritten into a complete question, and the right lane reads the graph and the databases.

Get a checked answer

Named places are checked against the graph, figures are computed from the data, and a "How I know this" panel names the sources.
